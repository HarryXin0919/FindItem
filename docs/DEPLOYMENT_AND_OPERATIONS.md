# Deployment and Operations

Production-like cabinet deployment should provide:
- five labeled controller modules;
- five labeled low-voltage power branches;
- fixed controller IDs;
- a controller-to-drawer map;
- spare ESP32-C3/controller parts;
- a replacement and reprovision workflow;
- software backup and database export procedure.

The final handoff must include how to replace CTRL-xx without changing application code.
